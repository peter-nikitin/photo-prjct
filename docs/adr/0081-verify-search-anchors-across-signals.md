# 0081: Проверять опоры расширения по согласованным признакам

- Status: Accepted
- Дата: 2026-11-20
- Авторы решения: владелец проекта; явное требование проверки опор по всем признакам
- Заменяет: [ADR 0076](0076-expand-face-results-with-person-appearance.md) в части принятия опор одежды только по лицевой близости
- Заменено: нет

## Контекст

Ошибочное совпадение лица может стать опорой одежды и привести новые кадры неподходящего
комплекта. Отдельное вычитание после расширения не устраняет источник этой ошибки: плохая
опора продолжает влиять на сравнение остальных кадров.

## Мотивы

- Проверять опору до использования в зависимом расширении.
- Совмещать лицо, фигуру, качество, форму, цвет и доступные детали головы.
- Не превращать неизвестный признак в подтверждение или доказательство другой личности.

## Рассмотренные варианты

1. Доверять опорам только по лицевой близости и фильтровать новые кадры после расширения.
2. Проверять совместимость опор по всем пригодным признакам перед зависимым поиском.
3. Объединять все векторы одним средним представлением без отдельных причин решений.

## Решение

Выбран вариант 2. При включённой проверке одежды общий подготовительный этап проверяет
кандидатов в опоры перед расширением по лицевому центроиду и одежде. Требуются совместимое
актуальное превью, однозначная связь лица и фигуры, пригодное качество, согласованность
лицевых векторов, формы и цвета. Детали головы проверяются, если обе стороны имеют пригодный
дескриптор. Отсутствие такого дескриптора фиксируется как неизвестность, а не несовпадение.

Для поиска из галереи выбранная пользователем фигура является исходным референсом. Остальные
опоры должны согласовываться со всем принятым набором. Для селфи одежда загруженного снимка
не считается формой мероприятия: референс выбирается из единственной наиболее поддержанной
согласованной группы кадров мероприятия. Один неподтверждённый кандидат или неоднозначный
выбор не дают оснований для новых опор одежды и автоматического вычитания.

Проверка ограничена небольшим ближайшим пулом кандидатов. Новые совпадения не становятся
опорами в том же поиске; граф мероприятия не строится. Принятые и отклонённые опоры сохраняются
с причинами и значениями признаков независимо от дальнейшего скрытия результатов.

При отсутствии совместимого покрытия внешности сохраняется обычное лицевое поведение с явным
результатом «нет данных». При наличии отрицательных свидетельств опора не используется для
зависимого расширения. Выключенная функция сохраняет прежний путь лица без чтения внешности.
Ошибка проверки обрабатывается как ошибка включённой стадии по ADR 0079.

Конкретные численные пороги, ограничения пула и выбор референса определяются версионированной
политикой поиска и описываются в алгоритме. Согласованность признаков не является доказанной
идентичностью; качество проверяется на размеченных случаях отдельно от производительности.

## Последствия

### Положительные

- Неподходящая опора не расширяет выдачу до последующего вычитания.
- Каждое решение проверяемо по отдельным признакам и исходным связям.

### Отрицательные

- Строгая проверка сокращает доступный набор опор и может уменьшить полноту расширения.
- При недостатке признаков часть возможностей остаётся недоступной; неопределённость видна в аудите.

## Проверка и откат

Проверить противоречащую форму при близком лице, неизвестные признаки, разные ракурсы,
групповые кадры, отсутствие покрытия, одинаковую политику зависимых стадий и ограниченный
объём SQL. Откат новых поисков — выключение проверки одежды; исходные признаки и готовые
снимки не изменяются.
