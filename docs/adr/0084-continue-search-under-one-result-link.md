# 0084. Продолжать поиск под одной ссылкой

- Status: Accepted
- Дата: 2026-11-21
- Решение: владелец проекта
- Заменяет: [ADR 0071](0071-prepare-photo-archives-in-background.md) в части состава бесплатного архива поиска

## Контекст

В разных ракурсах совпадение с исходным лицом может опуститься ниже порога. Пользователь уже видит фотографии, от которых полезно продолжить поиск. Отдельные независимые ссылки мешают просматривать найденное и скачивать его целиком.

## Решение

Одна публичная ссылка открывает исходный поиск и его завершённые проходы. Проход запускается явно: выбором кадра из видимой выдачи или автоматическим подбором нескольких ещё не использованных опор. Исполнитель обрабатывает один активный проход на поиск. Снимки результатов сохраняются отдельно, а публичная выдача показывает каждый кадр в первом проходе, где он доступен.

Автоматическое продолжение использует несколько лицевых центроидов из различных групп подходящих опор. Результат предыдущего прохода получает право стать опорой после проверки пригодности и происхождения. Ручное продолжение выбирает лицо по указанному пользователем кадру в рамках доступной выдачи.

Обратимая ручная отметка «Это не я» действует в пределах одной ссылки. Совпадения с отмеченным лицом приглушаются в сохранённой выдаче и фильтруются в последующих проходах. Исходные связи сохраняются для анализа и восстановления выдачи после отмены отметки.

В поиске по селфи новый загруженный кадр может быть самостоятельной опорой для очередного прохода. Он использует тот же жизненный цикл временного файла и очередь распознавания. Исходный снимок и все завершённые проходы остаются под той же ссылкой.

Архив бесплатной выдачи охватывает все её доступные оригиналы со всех проходов. Ручная отметка исключает оригинал из архива. Автоматическое приглушение сохраняет оригинал в архиве. Изменение набора создаёт другой архив с собственным сроком жизни. Авторизация оригиналов и фоновая сборка следуют ADR 0071.

## Последствия

Отдельные снимки сохраняют происхождение фото и позволяют повторить неудачный проход. Верхняя граница числа опор и один активный проход сдерживают нагрузку от повторных нажатий. Общая выдача и архив могут расти.

## Проверка

Проверить допуск к выбранному кадру по исходной ссылке, повторный запуск, отсутствие дублей в выдаче, порядок проходов, готовность архива по изменившемуся набору и права на оригиналы.
