# Алерты и внешняя проверка после восстановления

Подготовленный baseline одной VM охватывает только графики Linux, HTTP и PostgreSQL; до отдельной
активации свежие серии и стоимость не подтверждены. Dashboard сам по себе не оповещает о сбоях.

Внешний checker, правила и доставка уведомлений отложены: они не блокируют выпуск графиков.
Вернуться к ним до регулярной нагрузки или при появлении требования к времени обнаружения отказа:
определить независимое место проверки, измерить стоимость, согласовать правила и каналы, затем
подтвердить контролируемый отказ и восстановление уведомления. Прежняя image-origin VM остановлена;
ADR 0039 не переносит внешний probe на наблюдаемую VM.
