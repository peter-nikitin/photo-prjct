# Поиск фотографий по лицу

Селфи и выбранное лицо на фотографии галереи используют один алгоритм. Распознавание
селфи получает вектор AdaFace. Для выбранного лица галереи вектор уже хранится в
PostgreSQL. Затем общий исполнитель очереди сравнивает вход с принятыми векторами
доступных фотографий одного мероприятия.

## Прямой поиск

Косинусное расстояние не выше 0,42 включает фотографию в результат. Для группового
кадра выбирается ближайшее лицо. Каждая фотография появляется один раз. Прямая
выдача становится исходным набором для дополнительного поиска.

## Поиск по центроиду

Кандидаты в опоры берутся из прямой выдачи на расстоянии до 0,38 от исходного лица.
В принятой попытке обработки кадра должно быть ровно одно обнаруженное лицо.
При подсчёте учитываются лица, отклонённые по качеству. Исходное фото запроса
из галереи исключается из опор.

Кандидаты упорядочиваются по расстоянию до исходного лица, ID фото и UUID детекции.
Поиск берёт до пяти ближайших кандидатов, расстояние которых до первой опоры
не превышает 0,35. PostgreSQL приводит каждый вектор к единичной длине,
усредняет векторы опор и нормализует полученный центроид. Исходный вектор запроса
в среднее не входит. При одной опоре поиск использует её направление.
При отсутствии опор дополнительная выдача пуста.

Тот же SQL-запрос ищет по центроиду среди принятых векторов доступных фотографий
мероприятия. Для добавления кадра достаточно одного лица на расстоянии не выше 0,42.
Если подходят несколько лиц, выбирается ближайшее. Новые кадры не становятся
опорами. Уже найденные прямым или кластерным путём фотографии не дублируются.

## Результат и аналитика

Готовая выдача сохраняется как снимок. Расстояния по-прежнему определяют совпадения
и выбор опор. При показе Django проверяет текущую доступность сохранённых кадров
и сортирует кадры каждого прохода по времени съёмки от ранних кадров к поздним.
Кадры без времени идут в конце. При одинаковом или отсутствующем времени порядок
задаёт ID фото по возрастанию. Повторяющееся фото показывается в первом доступном
проходе. Состав и внутренний `rank` снимка сохраняются.

Для анализа качества сохраняются совпавшее лицо, расстояние до центроида и
упорядоченный список всех использованных опор. Сохранённые ранее результаты
поиска по отдельным опорам сохраняют исходное расстояние и единственный источник.
Выбор опор выполняется для каждого нового поиска, центроид не сохраняется.

Правило зависит от качества детекции и векторов. Одно обнаруженное лицо не
гарантирует отсутствие других людей на снимке. Отсутствие архивной разметки
оставляет принадлежность нового кадра неизвестной.

[Исходное решение о расширении, ADR 0070](adr/0070-expand-face-search-from-direct-matches.md)

## Совместная проверка опор внешностью

При включённой проверке одежды опоры лицевого центроида проходят общий этап проверки
согласованности лица, фигуры, качества, формы, цвета и доступных деталей головы до
расширения. Отклонённые опоры сохраняются с причинами. При выключенной функции прежний
лицевой путь остаётся неизменным; отсутствие совместимого покрытия внешности имеет
отдельный исход, отличный от отрицательной проверки.

## Продолжение поиска

«Найти по этому фото» запускает проход от выбранного найденного кадра, если в нём есть
одно пригодное лицо. Кадр из центроида можно выбрать для отдельного ручного прохода.
Выбранное лицо запускает тот же проход, что и поиск из галереи, и сохраняет новые кадры
под существующей ссылкой. На странице под текущими результатами появляется разделитель
со статусом. После окончания браузер сверяет сохранённую выдачу и добавляет новый блок.
Загрузка селфи или поиск из галереи создают отдельный поиск. Можно повторно искать по тому же
кадру. Фото, уже показанные в предыдущих блоках, занимают в выдаче одно место.

Добровольная отправка селфи для обратной связи относится к первому файлу поиска.
Бесплатный архив включает видимые оригиналы со всех проходов. Ручная отметка «Это не я»
исключает кадр из следующего скачивания. Автоматически приглушённые карточки остаются
в архиве. При скачивании сервер проверяет актуальный состав и использует готовый архив
для того же набора оригиналов.

### Отметка «Это не я»

Повторное нажатие снимает ручную отметку. Пока она активна, UI приглушает карточку
и уверенные совпадения с тем же лицом в сохранённой выдаче. Используется лицо,
которое дало совпадение с поиском. При конфликте с сильной положительной опорой
автоматическая отметка не ставится. Учитываются только ручные отметки этого поиска.
Если пригодного связанного лица нет, приглушается только вручную отмеченная карточка.

Ручная отметка блокирует поиск по этому кадру. Сильное соответствие активной отметке скрывает новые находки. Сохранённое
совпадение и его исходные признаки позволяют вернуть находку в выдачу после снятия
отметки, если оставшиеся отметки её не исключают.
