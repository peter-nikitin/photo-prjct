# Согласовать ADR лицевого расширения с центроидным алгоритмом

Наблюдение: после PR #346 `selfie_search/services/anchor_expansion.py` выбирает до пяти
согласованных опор и ищет одним нормализованным центроидом. Принятый ADR 0070 по-прежнему
описывает до трёх разнообразных опор и совпадение хотя бы с одной из них.

Это не блокирует внешность: новый этап читает существующие результаты лица, не меняет его
алгоритм, а собственные индивидуальные опоры описаны отдельно в ADR 0076. Тесты лица
продолжают проверять действующий код; перенос порогов между пространствами запрещён.

Триггер возврата: следующее изменение алгоритма или порогов лицевого расширения либо
подготовка его публичной активации. Тогда записать отдельный ADR, заменяющий нужную часть
0070, с фактическими источниками экспериментальных доказательств центроида; старый принятый
текст не переписывать задним числом. Перепроверить параметры и PR перед принятием решения.
