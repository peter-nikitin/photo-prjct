# Восстановить CDN origin после появления доступа к DNS

Сейчас оба CDN gate включены, но CDN preview и обложки возвращают 504: DNS
`img-origin.findme-photo.ru` указывает на `84.252.136.164`, прежнюю остановленную ВМ. Изменить
эту DNS-запись сейчас нельзя, поэтому текущий этап восстанавливает NLB и HTTPS сайта без CDN;
нерабочий CDN не блокирует этот ограниченный этап по решению владельца.

Когда появится доступ к изменению DNS, направить A-запись `img-origin.findme-photo.ru` на
постоянный адрес NLB `111.88.151.64`. В отдельном проверенном изменении разместить imgproxy и
origin vhost на общей ВМ, добавить имя в SAN сертификата, сохранить существующие ограничения
подписей, разрешённых путей, заголовка и отдельные read-only S3 credentials. Проверить реальную
цепочку S3 → gallery preview и cover через CDN, отказ без прав, отсутствие утечек и продление
сертификата. До фактической проверки не считать CDN восстановленным и не менять gates автоматически.
