# 0071: Проверять выбранные опоры по первой опоре без замены

- Status: Accepted
- Дата: 2026-11-19
- Авторы решения: владелец проекта
- Заменяет: [ADR 0070](0070-expand-face-search-from-direct-matches.md) в части окончательного отбора опор
- Заменено: нет

## Контекст

Прямой поиск может включить фотографию другого участника. Выбор отличающихся опор
способен включить такое совпадение и расширить выдачу на другие фотографии этого
участника. В примере с Чемпионата России среди любителей кадр с другой формой
прошёл порог до исходного лица 0,38 и стал дополнительной опорой.

Если ограничивать кандидатов до выбора второй и третьей опор, ужесточение порога
меняет сами опоры и способно увеличить выдачу. Для оценки фильтра и управления
ошибками требуется отсев уже выбранного набора.

## Рассмотренные варианты

1. Проверять согласованность кандидатов до выбора опор, заполняя до трёх мест.
2. Сначала выбрать до трёх опор, затем отсеять несогласованные без замены.

## Решение

Выбран вариант 2. Первоначальный выбор до трёх опор следует ADR 0070. После этого
для каждой выбранной опоры рассчитывается расстояние до первой, самой уверенной
опоры. В дополнительном поиске участвуют только опоры с расстоянием не выше 0,35.
Первая опора сохраняется. Освободившиеся места остаются пустыми. Исходная вторая
участвует в первоначальном выборе третьей, даже если затем будет отсеяна.

Отбор и сравнение остаются внутри одного SQL-запроса для селфи и галереи.
Для нового кадра достаточно совпадения хотя бы с одной оставшейся опорой
при расстоянии не выше 0,42. Прямой поиск сохраняет действующее правило.

## Последствия

Фильтр не добавляет новых опор. Его ужесточение при том же исходном наборе
может только сократить дополнительные результаты. Ошибка первой опоры и
ошибочные совпадения с согласованными опорами остаются возможными. Порог 0,35
выбран по ограниченной выборке и нуждается в дальнейшей оценке качества.

## Проверка и откат

Проверить отсев без замены при наличии других подходящих кандидатов, границу 0,35,
участие первой опоры и прежнее число SQL-запросов. Повторить архивные запросы и
пример с другой формой, отдельно учитывая архивные отметки, визуальную оценку
экипировки и неизвестные кадры. Управление выпуском использует существующий флаг
расширения через Django Admin.
