# Мониторинг image origin

Конфигурация Unified Agent для image origin сохраняется в этом каталоге и доставляется
через [workflow](../../../.github/workflows/deploy-image-origin.yml). Прежние правила
алертов и дашборд нескольких VM удалены; восстановление мониторинга image origin требует
отдельной проверки источников и настройки сигналов.
