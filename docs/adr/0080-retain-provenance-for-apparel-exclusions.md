# 0080: Сохранять исходные совпадения при вычитании по одежде

- Status: Accepted
- Дата: 2026-11-20
- Авторы решения: владелец проекта; явное требование вычитания с сохранением исходной связи
- Заменяет: [ADR 0076](0076-expand-face-results-with-person-appearance.md) только в части запрета автоматического исключения из пользовательской выдачи
- Заменено: нет

## Контекст

Проверка одежды может уверенно противоречить совпадению лица. Одних рекомендаций недостаточно:
неподходящий кадр продолжает показываться пользователю. Физическое удаление результата лишит
оператора возможности проверить исходное совпадение и затронет ссылки найденных кадров на опоры.

## Мотивы

- Показывать пользователю результат с вычетом уверенных несовпадений.
- Сохранять исходную выдачу и причинную связь каждого решения для последующего анализа.
- Отделять недостаток данных от доказательства несовпадения и ограничивать потерю нужных кадров.

## Рассмотренные варианты

1. Оставлять все решения рекомендациями без изменения пользовательской выдачи.
2. Удалять неподходящие строки результата и их свидетельства.
3. Сохранять полный снимок совпадений, помечая исключённую часть для публичного чтения.

## Решение

Выбран вариант 3. Исходные строки результата, ранги, источники и прямые, центроидные и
кластерные связи сохраняются. Уверенное исключение является отдельным неизменяемым решением
того же снимка: фиксируются найденное лицо и фигура, проверенные опоры, значения признаков,
причина и версия правил. Исключённый кадр остаётся доступен оператору для анализа.

Публичная страница, её счётчик, медиа результата, скачивания, архив и пользовательская разметка
используют одну видимую часть снимка. Объём исходных совпадений и объём исключений считаются
отдельно. Исключение из поиска не удаляет фотографию мероприятия и не меняет её общую доступность.

Автоматическое вычитание требует выраженного согласованного противоречия формы и цвета всем
проверенным опорам. Обычный порог поиска и слабая рекомендация не являются достаточным
основанием. Недостающие признаки, неоднозначная связь и непригодная фигура остаются
неопределённостью. Наличие подходящей или неопределённой фигуры на групповом кадре защищает
фотографию от уверенного исключения. Выбранный пользователем исходный кадр не исключается.

Новые правила применяются при публикации нового поиска. Сохранённые снимки и ручная разметка
не пересчитываются при выкладке или переключении функции. При выключенной проверке одежды
работает прежний лицевой поиск без вычитания. Ошибки обязательной включённой стадии
обрабатываются по ADR 0079.

## Последствия

### Положительные

- Пользователь не видит уверенно неподходящую часть новой выдачи.
- Оператор может восстановить исходную связь и оценить ошибки исключения.
- Сохраняются ссылки на опоры и сопоставимые исходные счётчики.

### Отрицательные

- Хранится больше результатов, чем показывается пользователю.
- Консервативная политика оставляет часть спорных кадров; её качество требует разметки.

## Проверка и откат

Проверить неизменность исходных связей и рангов, все публичные читатели и счётчики, групповые
кадры, неизвестные признаки, атомарность публикации и обновление непустой базы без пересчёта
истории. Для остановки вычитания в новых поисках выключить проверку одежды через Admin;
готовые снимки сохраняются.
