# Поиск фотографий по лицу

Селфи и выбранное лицо на фотографии галереи используют один алгоритм. Распознавание
селфи получает вектор AdaFace. Для выбранного лица галереи вектор уже хранится в
PostgreSQL. Затем общий исполнитель очереди сравнивает вход с принятыми векторами
доступных фотографий одного мероприятия.

## Прямой поиск

Косинусное расстояние не выше 0,42 включает фотографию в результат. Для группового
кадра выбирается ближайшее лицо. Каждая фотография появляется один раз. Прямая
выдача становится исходным набором для дополнительного поиска.

## Дополнительные опоры

Из прямой выдачи выбираются до трёх фотографий. Каждая должна иметь ровно одно
обнаруженное лицо в принятой попытке обработки. При подсчёте учитываются и лица,
отклонённые по качеству. Расстояние до исходного лица должно быть не выше 0,38.
Исходное фото запроса из галереи пропускается.

Первая опора — ближайшая к исходному лицу. Каждая следующая максимизирует расстояние
до ближайшей из уже выбранных опор. Это позволяет использовать несколько ракурсов.
Если подходящих фотографий меньше трёх, поиск использует доступные опоры.

Один SQL-запрос выбирает опоры и ищет от них новые фотографии по полному корпусу
мероприятия. Для добавления достаточно одного лица на расстоянии не выше 0,42 от
любой опоры. Новые фото сами не становятся опорами. Уже найденные прямым или
кластерным путём фотографии не дублируются.

## Результат и аналитика

Готовая выдача сохраняется как снимок. При показе проверяется текущая доступность
каждой фотографии. Прямые и кластерные результаты сохраняют существующий порядок,
дополнения следуют за ними в порядке расстояния и ID фото.

Связь дополнительного кадра с опорой и совпавшим лицом сохраняется для аналитики
качества. Это позволяет сопоставлять обратную связь с происхождением попадания.
Выбор опор остаётся вычислением времени выполнения. Сохранённая аналитика не
служит источником новых опор.

Правило зависит от качества детекции и векторов. Одно обнаруженное лицо не
гарантирует отсутствие других людей на снимке. Отсутствие архивной разметки
оставляет принадлежность нового кадра неизвестной.
