# Удалить снятую идентичность из отдельного bib-local стенда

При проверке обычного локального worker обнаружено, что отдельный preset
`docker-compose.bib-local.yml:67` тоже объявляет `2/face_embedding/3`. Текущий runner её
не поддерживает; штатная локальная конфигурация исправлена в задаче внешности.

Это прежнее расхождение не относится к новому процессору: bib-local preset в этой задаче
не используется и не меняется. Production Compose объявляет действующие контракты отдельно.

Триггер возврата: следующий запуск или изменение отдельного bib-local стенда. Удалить
снятую идентичность и проверить итоговый набор через реальный `WorkerConfig.from_env`,
затем повторить существующую приёмку bib-local. Не добавлять поддержку снятого процессора
в runtime ради старого шаблона.
